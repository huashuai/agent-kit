# Lessons from merged work

Each night an agent reviews the day's commits for what had to be fixed
again, what shouldn't have merged, and what was verified too thinly. What
it learns is kept here. Read this before changing code.

Each lesson is a rule, then why, then the evidence (commit hashes, PR or
issue numbers). "Seen" counts the separate days a review found it. A lesson
seen on 3 or more days moves into
[docs/code-standards.md](docs/code-standards.md). A lesson seen once that
doesn't recur within 30 days is dropped.
